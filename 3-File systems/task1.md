# ФС

1) Какие файловые системы вы знаете?

Ext (extended) FS - расширенная файловая система, одна из первых
ext2 - более расширенная файловая система. Изменения от первой касаются интерфейса, конфигурации, увеличения объем памяти, производительности.
ext3 - третье поколение ext fs. В отличие от предыдущих, относится к журналируемым файловым системам.
ext4 - четвертое поколение. Максимально убраны всевозможные ограничения, присутствующие в предыдущих версиях.
xfs - тоже эурналируемая. Отличительная особенность: в логи программа будет записывать только изменения в метаданных. Из преимуществ выделяют быстроту работы с объемной информацией, способность выделять место для хранения в отложенном режиме
btrfs - Отличается повышенной стойкостью к отказам и высокой производительностью. Удобная в работе, позволяет легко восстанавливать информацию

2) Как можно классифиировать файловые системы? в чём отличия?

Файловые системы можно разделить на журналируемые и нежурналируемые

Журналируемые сохраняют историю манипуляций пользователя и позволяют ее посмотреть, выполнить диагностику системы в отдельном специальном файле. Отличаются повышенной стойкостью к сбоям в функционировании, сохранностью целостности данных. 

В нежурналируемых не предусмотрено сохранение логов

3) Какие файловые системы используются в linux?

ext, xfs, btrfs, tmpfs

4) Как можно создать файловую систему на диске?

Команда mkfs
```bash
mkfs [опции] [-t тип_файловой_системы] [опции_файловой_системы] устройство
```

5) Как можно подключить диск в систему, что такое монтирование?

```bash
mount /dev/sdb1 /mnt/mydisk
```

Монтирование — это процесс подключения файловой системы устройства (диска, раздела) к каталогу в дереве каталогов.


6) файловая система procfs, cifs, tpmfs,sysfs. В чём особенности каждой из них?
Вывести каталоги к которым примонтированы эти файловые системыю

procfs (/proc) — виртуальная ФС для информации о процессах и ядре.

cifs — для сетевых ресурсов Windows/Samba.

tmpfs (/dev/shm) — ФС в ОЗУ для временных файлов.

sysfs (/sys) — виртуальная ФС для данных об устройствах, драйверах и ядре.

7) Как можно получить информацию о системе используя лишь команду cat?
вывести ифонмацию о процессоре и состоянии памяти системы

```bash
cat /proc/cpuinfo
cat /proc/meminfo
```
