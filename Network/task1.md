
# сети

1. Выведите список интерфейсов, какими способами можно это сделать?

```bash
ip link show
```
```bash
ip addr show
```

2. Попробуйте изменить ip адрес

Попробовал
```bash
ip addr change 192.168.1.100/24 dev enp0s3
```

3. Попробуте добавить несколько ip адресов на сетевую карту

```bash
ip addr add 192.168.1.101/24 dev enp0s3
ip addr add 192.168.1.102/24 dev enp0s3
```

4. Выведите список маршрутов

```bash
ip route show
```

5. Выведите arp таблицу

```bash
ip neigh
```

6. Что такое ip адрес?

IP-адрес — это уникальный логический адрес устройства в сети, используемый для его идентификации и передачи сетевых пакетов.

7. Для чего нужны маршруты?

Маршруты определяют путь следования сетевых пакетов от источника к получателю через интерфейсы и шлюзы.

8. Что за протокол arp?

протокол, предназначенный для определения MAC-адреса устройства по его IP-адресу в локальной сети.

9. Что такое dhcp?

протокол автоматической настройки сети, который выдаёт устройствам IP-адрес и другие сетевые параметры.

10. Что такое dns?

система преобразования доменных имён в IP-адреса.

11. Как называется один из протоколов синхронизации времени?

NTP (Network Time Protocol).

12. Что такое широковещательный запрос, зачем он нужен?

это сетевой пакет, отправляемый всем узлам сети для поиска устройств или служб.

13. Какой адресс является широковещательным?

В IPv4 255.255.255.255 или последний адрес подсети, например 192.168.1.255.

14. Какие ещё параметры можно задать сетевой карте?

IP-адрес, маску подсети, MAC-адрес, MTU, скорость, режим duplex и VLAN.

15. Что такое маска подсети? зачем она нужна?

Маска подсети определяет границу между адресом сети и адресом узла и используется для маршрутизации трафика.
