# Журнальчики

1. Посмотретите журналы ssh

```bash
journalctl -u ssh
```
Посмотрел

2. Выведите журналы в реальном времени

```bash
journalctl -f
```

3. Выведите лог в реальном времени для службы sshd

```bash
journalctl -u sshd -f
```

4. Можно ли без комады journalctl прочитать логи systemd?

Да, логи хранятся в бинарном формате в /var/log/journal, но структура нечитабельна. Рекомендуется использовать journalctl

5. Сколько будет 2-2?

2 - 2 = 0
